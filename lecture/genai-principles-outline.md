# /genai 덱 — 생성형 AI 원리 (범용판) 설계서

> 2026-09-16 전면 재작성. 이전 버전(절주서포터즈 전용, 24장)은 커밋 `8a365b3`에 보존.
> 이 덱은 **특정 도메인·기관 내용 없음**. 어디서든 쓸 수 있는 원리 강의.

## 한 줄 주장 (throughline)

**생성은 주문이 아니라 조건 설계다.**
프롬프트 = 조건. 참조 이미지 = 같은 공간의 조건. 첫 프레임 = 조건.
노드 그래프 = 조건의 사슬을 밖으로 꺼낸 것.
→ "잘 만드는 법"은 전부 한 문장에서 유도된다: **조건을 더하거나, 조건을 잠근다.**

이 문장을 02에서 심고 09 · 15 · 18 · 22에서 다시 친다.

## 슬라이드 (28장, 00~27)

### Part 0 — 프레임
- **00 Title** — 「조건을 좁히는 일」 · 생성형 AI는 어떤 로직으로 만들어지는가
- **01 Thesis** — 도구는 6개월마다 바뀌고 원리는 안 바뀐다. 이 강의는 원리 → 유도된 실전.
- **02 공통 구조 지도** — 조건 → 확률 분포 → 표본 추출 → 결과. 텍스트·이미지·영상이 다른 건 "무엇을 뽑는가"뿐.

### Part 1 — LLM 기초
- **03 토큰** — 글자가 아니라 조각을 본다. 한국어는 더 잘게 쪼개진다. 글자 수 세기·거꾸로 쓰기가 약한 이유. 토큰 = 과금·컨텍스트의 단위.
- **04 임베딩** — 뜻이 좌표가 된다. 가까운 좌표 = 비슷한 맥락. **복선: 이미지도 같은 방식으로 좌표가 되고, 텍스트와 이미지를 한 공간에 놓는 것이 「글로 그림을 부르는」 다리(CLIP)다.**
- **05 어텐션** — 문맥이 좌표를 바꾼다("배"). 그래서 프롬프트의 순서·근접성이 결과를 바꾸고, 무관한 지시를 몰아넣으면 희석된다.
- **06 표본 추출** — temperature/top-p = 분포의 뾰족함. 시드 = 같은 조건이면 같은 결과. 학습 목표가 「참」이 아니라 「그럴듯함」이라 자신 있게 틀린다. 다시 굴리기 = 표본을 더 뽑는 것.
- **07 학습 3단계** — 사전학습(지식·문체) / 지시학습(대화 형식) / 선호학습(공손·거절·장황함). 기본 말투는 훈련된 습관 → 역할·형식 지정으로 덮어쓴다.
- **08 컨텍스트** — 가중치는 안 변한다. 대화에 준 것만이 작업기억. RAG·검색 = 답 전에 문서를 붙이는 조건화. 컷오프 이후·내부 자료는 안에 없다. 긴 컨텍스트는 중간이 묻힌다.
- **09 브릿지(LLM 실전)** — 프롬프트 5칸: 역할·목표 / 근거 입력 / 출력 골격 / 제약 / 예시. 예시가 규칙 설명보다 강한 이유 = 모델은 규칙이 아니라 패턴을 따른다.

### Part 2 — 이미지
- **10 잠재공간** — 1024²×3 = 300만 숫자를 그대로 못 다룬다. 압축 좌표에서 그리고 마지막에 디코더가 펼친다. 함의: 픽셀 편집이 아니라 좌표를 옮겨 **다시 그린다**.
- **11 디퓨전 + 시드** — 학습=낀 노이즈 맞히기, 생성=순수 노이즈에서 20~50번 빼기. 시드 = 출발 노이즈.
- **12 조건화 + 가이던스** — 텍스트 임베딩이 매 스텝 방향키. CFG = 조건을 얼마나 강하게 따를지(과하면 과포화). 네거티브 프롬프트는 디퓨전 계열의 장치이지 모든 모델의 장치가 아니다.
- **13 참조 5경로 (핵심)** — 무엇을 넘기고 무엇이 잠기는가:
  1. 텍스트만(t2i) — 잠기는 것 없음 — 탐색
  2. img2img(강도) — 출발 노이즈를 원본에서 — 전체 구도·색 — 리터치·스타일 변환
  3. 구조 참조(뎁스·포즈·엣지/ControlNet류) — 기하 — 구도·자세·윤곽 — 같은 레이아웃 다른 내용
  4. 정체성·스타일 참조(이미지 임베딩 주입/IP-Adapter류) — 이미지를 「말처럼」 — 인물·화풍 — 같은 얼굴 여러 장면
  5. 파인튜닝(LoRA·DreamBooth) — 가중치에 개념을 새김 — 개념 전체 — 반복 사용하는 캐릭터·브랜드
- **14 왜 「비슷한」 게 나오나** — 복사가 아니라 좌표 근처에서 재생성. 점이 아니라 영역을 가리키므로 닮았지만 다르다. 두 계보: (a) 디퓨전+어댑터 = 별도 통로 주입, 슬라이더 많음 / (b) 네이티브 멀티모달(GPT Image·Nano Banana 계열) = 이미지를 텍스트와 같은 시퀀스의 토큰으로 읽어 **참조를 문맥처럼** 보고 편집이 대화의 다음 턴이 된다. ⚠️ 내부 구조는 비공개 부분이 있으므로 「문맥처럼 읽는다」까지만 주장한다. 공통 한계: 어느 쪽이든 재생성이라 원본 픽셀 보존은 보장되지 않는다.
- **15 이미지 실전** — 6축(주체/구도·행위/광원/렌즈/질감·매체/색·톤). 형용사보다 명사와 수치. 실증: 색은 퍼센트 배분, 렌즈는 화각(도) — 기하·비율을 특정하는 게 기술. 금지보다 긍정 잠금. 시드 고정 + 한 번에 하나만.

### Part 3 — 영상
- **16 시공간 패치** — 프레임을 시간까지 묶어 조각내고 트랜스포머+디퓨전으로 한꺼번에. 5초 = 이미지 수백 장어치 계산 → 짧은 클립이 표준 단위인 구조적 이유.
- **17 3대 난제** — 정체성 드리프트 / 물리 엔진 없음(본 적 있는 움직임의 통계) / 카메라·컷 권한을 안 가져오면 모델이 가져간다. + 「천천히」는 프레임 수로 번역되지 않는다.
- **18 영상의 조건들** — i2v 첫 프레임이 가장 강한 조건(이미지에서 통제한 걸 물려준다) / 끝 프레임·키프레임 / 참조 인물 고정 / 카메라 프리셋 / 오디오는 「없음」도 조건. 영상 프롬프트는 묘사가 아니라 **샷 지시서**: 구조 선언 → 비트별 초 배정 → 카메라 → 금지.

### Part 4 — 왜 노드인가
- **19 한 모델이 다 못한다** — 강점이 갈린다(인물 일관성/배경 질감/타이포/모션/립싱크/업스케일/사운드). 실증: 2,142편에서 부서별로 쓰는 모델이 갈렸다. 「최고 모델 하나 찾기」가 아니라 **역할 배치**.
- **20 그래프 해부** — 한 장 생성도 사슬이다: 로드 → 인코딩(조건) → 샘플러(시드·스텝·가이던스) → 디코더 → 후처리. 노드 = 그 칸을 밖으로 꺼낸 것. 꺼내면 생기는 것 3가지: 중간 산출물 재사용 / 부분 교체 / 분기·배치. 다시 굴리기가 「전체」가 아니라 「한 칸만」이 된다.
- **21 앱 = 프리셋 포장** — 스펙트럼: 채팅 한 줄 ↔ 프리셋 앱(힉스필드류) ↔ 노드 편집기(ComfyUI류). 프리셋 앱 = 검증된 그래프를 버튼으로. 교환: 편의를 얻고 제어권을 잃는다 — 막히면 어느 칸에서 막혔는지 모른다. 원리를 알면 프리셋 앱에서도 어느 칸을 만지는지 안다.
- **22 재현성·에셋 바이블** — 좋은 결과는 조건을 기록해야 다시 온다(시드·모델 버전·참조·파라미터·원문). 캐릭터/로케이션/소품을 판(plate)으로 관리. 실증: 규모를 맞춰도 남는 차이가 이 정리 습관이고, 상위권은 샷당 결합 에셋이 더 많고 프롬프트 **종류는 오히려 적다**(= 같은 판 재사용).

### Part 5 — 그래서 잘 만드는 법
- **23 실증** — 공개 출품작 2,142편 · 생성 42만 건 · 프롬프트 18만 건 분석(강사 자체 분석, 2026-08).
  1위 변수는 문장력이 아니라 **물량**(상위 중앙값 생성 283·폴더 9 vs 하위 71·1).
  규모를 맞추면 프롬프트 특징 29개 중 남는 게 거의 없다. 남은 것 = 에셋 폴더 정리(1.4~1.5배).
  **역전**: 「보존·금지」 지시는 오히려 하위권 쪽(0.82배) — 상위권은 긍정문으로 재진술.
  착시 경고: 리프트가 클수록 한 작가의 사투리다(한 작품이 수치 전부를 만든 사례 다수) → 남의 매직 프롬프트를 베끼지 마라.
- **24 6원칙** — ①분포를 좁혀라 ②조건을 쌓아라 ③단계를 나눠라 ④고정과 변주를 분리하라 ⑤금지 대신 긍정 잠금 ⑥표본을 늘려라(단 한 번에 하나만 바꾼다).
- **25 문법 3열** — 텍스트/이미지/영상 × (조건의 종류 · 잠그는 법 · 흔드는 법 · 검증).
- **26 증상 → 원인** — 매번 다른 얼굴/지시 무시/글자 깨짐/사실 오류/과포화/원본 변형/제멋대로 컷/부자연한 움직임 각각을 「어느 칸의 문제」로 되돌린다.
- **27 Closing** — 좋은 프롬프트는 잘 쓴 문장이 아니라 **잘 좁힌 조건**이다.
