## 2. 설계 철학

- AI = "족보를 통째로 외웠지만 병동 경험은 0인 신입 인턴" — 원리 강의가 아니라 '부려먹고 검수하는 업무 관계'로 가르친다.
- 라이브 환각 유도 데모로 **맹신하기 전에 안전하게 배신당하는 경험**을 먼저 시킨다 (건강정보 도메인이라 특히 중요).
- 모든 기법을 디자인단의 실제 활동(카드뉴스 제작 + 가이드라인 미준수 콘텐츠 모니터링)에 1:1 매핑 — 강의가 끝나면 복붙 템플릿 6개가 남는다.
- KHEPI 가이드라인 10원칙(이용자 5수칙 + 생산자 5수칙)을 새 이론이 아닌 'AI 검증 수칙'으로 재활용.

## 5. 실습 세션 상세 설계 (40분, 150명)

**운영 원칙 — 전원 각자 실습 + 라이브 데모 병행**
- 각 STEP 시작 시 강사가 30~60초 라이브 시연 후 풀어준다. 강사 화면에 현재 STEP·대형 타이머 상시 표시.
- 개인 실습 + 옆사람 페어 허용 (기기·계정 없는 학생 구제 + 상호 교수). "막히면 손 들지 말고 옆 사람 화면 보기" 규칙으로 조교 없는 대규모 낙오 방지.
- 각 STEP 종료 시 정답 예시 화면 공유로 전원 기준선 정렬.
- 도구는 각자 무료 AI 아무거나(ChatGPT·Claude·Gemini) — "모델이 달라도 공식은 같다" 프레임으로 편차를 교육 포인트로 흡수.

**타임라인**: 브리핑 3분 → STEP 1 A/B 비교 10분 → STEP 2 카드뉴스 10분 → STEP 3 모니터링 10분(정식) → 공유 7분 — QR 접속·로그인은 직전 휴식 10분에 이미 완료

**실습 주제 3택 1** (전부 국가건강정보포털·식약처에 대조 근거 존재 + 온라인 과장 콘텐츠 빈발)
1. 유산균은 공복에 먹어야 한다?
2. 물 하루 2L, 꼭 마셔야 하나?
3. 카페인과 수면 — 하루 적정량은?

**준비물·백업 플랜**
- 템플릿 6종 전문+복사 버튼+채점표가 있는 독립 웹페이지 (기존 덱 `/homework` 라우트 패턴 재사용) + 대형 QR 슬라이드
- 라이브 데모 전 건의 사전 실행 캡처본을 슬라이드에 내장 (재현 실패·네트워크 장애 대비)
- 무료 한도 소진 대비 대체 경로 2개 이상 킷 페이지에 명시
- 와이파이 사전 확인, 불가 시 페어당 1기기 축소 운영
- 사전 공지 요청: "무료 AI 계정 미리 만들어 오기" (+휴식 10분에 로그인 시간을 확보해 이중 안전망)
- 강의 직전 전수 리허설 (무료 도구 UI 변동 잦음)

1. KHEPI 가이드라인 10원칙 재활용: 이용자 5수칙=AI 검증 수칙 / 생산자 5수칙=T3 제약 / 10원칙=T4 판정 기준 — 새 이론이 아니라 기존 교육의 강화로 포지셔닝
2. 'AI 생성 여부 표시' 권고 반영 — "AI 활용은 위반이 아니라 표기하면 부합"으로 명시 (체크리스트 4번)
3. 신뢰 출처 위계·화이트리스트를 프롬프트 고정 블록 겸 카드뉴스 출처 명기용으로
4. 실제 사고 사례 인용 시 슬라이드에 출처·조사 시점 병기 (강의 자체가 가이드라인 모범이어야 함) — 강의 직전 최신성 재확인
5. 빈발 오정보 표현('완치'·'기적의 치료'·'연예인이 몰래 먹는')의 이중 활용: T3 금지어 + T4 탐지 키워드 + 실습 가상 콘텐츠 트리거
6. 의학적 조언 경계: "진단·치료 수준 판단은 AI에게도 묻지 않는다" + 카드뉴스 마지막 장 '참고용·전문가 상담' 고지 슬롯
7. 모니터링 실습은 **가상 미준수 콘텐츠**로 진행 (실제 콘텐츠 지목의 법적·윤리 리스크 회피)
